1. Angle Properties (Sifat-Sifat Sudut)

  • Angles on a straight line = 180°
  • Angles around a point = 360°
  • Angles in a triangle = 180°
  • Angles in a quadrilateral = 360°
  • Isosceles triangle: two equal base angles.
  • Equilateral triangle: each angle = 60°.
  • Rectangle: all angles are 90°. Parallelogram: opposite angles are equal. Rhombus: all sides equal, opposite angles equal. Trapezium: one pair of parallel sides.

2. Circle (Lingkaran)

Area: A = πr²  •  Circumference: C = 2πr  •  Use π = 22/7

Example: r = 7 cm → A = 22/7 × 7 × 7 = 154 cm² • C = 2 × 22/7 × 7 = 44 cm

3. Semicircle (Setengah Lingkaran)

Area: A = ½πr²  •  Perimeter: P = πr + 2r (arc + diameter!)

Example: r = 7 cm → A = ½ × 154 = 77 cm² • P = 22 + 14 = 36 cm

4. Quarter Circle (Seperempat Lingkaran)

Area: A = ¼πr²  •  Perimeter: P = ½πr + 2r (arc + two radii!)

Example: r = 14 cm → A = ¼ × 616 = 154 cm² • P = 22 + 28 = 50 cm

5. Composite Shapes (Bangun Gabungan)

Split the shape into parts you know, then add (or subtract for a cut-out)!

  • Rectangle + semicircle: A = l×w + ½πr²
  • Capsule (rectangle + 2 semicircles): A = l×w + πr²
  • Semicircle on top of a rectangle: A = l×w + ½πr²
  • Rectangle with a semicircular cut-out: A = l×w − ½πr²
  • Quarter circle + rectangle: A = l×w + ¼πr²
  • Circle + rectangle (“key”): A = πr² + l×w

⚠️ Remember: Area uses square units (cm²). Perimeter uses linear units (cm). A semicircle perimeter includes the diameter; a quarter-circle perimeter includes two radii.
